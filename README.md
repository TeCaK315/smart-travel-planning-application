# Smart Travel Planning Application Dashboard

Дашборд для мониторинга Пользователи испытывают трудности с планированием путешествий, используя множество приложений и инструментов, что приводит к путанице и потере времени.

## 🎯 Проблема

Пользователи испытывают трудности с планированием путешествий, используя множество приложений и инструментов, что приводит к путанице и потере времени.

## 💡 Решение

Smart Travel Planning Application Dashboard - интерактивный дашборд для мониторинга и визуализации данных в реальном времени.

## ✨ Возможности

- **Реалtime данные** - автоматическое обновление каждую минуту
- **Интерактивные графики** - Area, Line, Pie charts
- **Фильтрация и поиск** - быстрый доступ к нужным данным
- **Экспорт в CSV** - выгрузка для дальнейшего анализа
- **Адаптивный дизайн** - работает на любых устройствах

современные компании

## 🚀 Быстрый старт

```bash
# Клонировать репозиторий
git clone <repo-url>
cd smart-travel-planning-application-dashboard

# Установить зависимости
npm install

# Запустить
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000)

## 📊 Подключение данных

Дашборд использует демо-данные по умолчанию. Для подключения реальных данных:

1. Создайте API endpoint в `src/app/api/data/route.ts`
2. Обновите fetcher в `src/app/page.tsx`
3. Настройте интервал обновления

## 🌐 Деплой на Vercel

1. Push в GitHub
2. Импортируйте в [Vercel](https://vercel.com)
3. Deploy!

## 📝 Tech Stack

- **Framework:** Next.js 14
- **Styling:** Tailwind CSS
- **Charts:** Recharts
- **Data Fetching:** SWR
- **Icons:** Lucide React
